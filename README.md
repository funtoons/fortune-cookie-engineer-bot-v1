## The fortune

> You will meet a stranger who fixes your bug tonight. The stranger is you, at 3 a.m., with no memory of writing it.

## How it works

`main.py` (Python standard library only, deterministic, offline) writes that
single line to `/output/entry.txt`:

```sh
python3 main.py
```

## Verification

Two runs with a cleared cache produce byte-identical output (see commit
history for the recorded hashes).
